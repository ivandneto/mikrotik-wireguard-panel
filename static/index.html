🚀 Primeiros passos

Siga esta ordem na primeira vez. Cada item mostra se já está feito:

  1. Conectar ao MikroTik — o selo no topo deve estar MikroTik online. Se não estiver, veja Problemas comuns.
  2. Informar a interface de internet — em Configurações → Interface WAN (ex.: pppoe-out1). Ativa o gráfico de internet.
  3. Configurar a VPN — em VPN WireGuard → Iniciar configuração. Feito uma única vez.
  4. Criar o primeiro cliente — VPN WireGuard → Novo cliente → escaneie o QR Code com o app WireGuard.
  5. ⬜Ativar alertas — em Alertas, configure o Discord e/ou Telegram e clique em "enviar teste".
  6. ⬜Trocar a senha do admin — menu lateral → 🔑 Trocar senha.

📊 Painel

Visão geral do que está acontecendo agora. Atualiza sozinho a cada 15 segundos (o botão ⟳ no topo força uma coleta imediata).

  • Roteador — modelo, versão do RouterOS e há quanto tempo está ligado.
  • CPU / Memória — uso atual. CPU alta por muito tempo pode deixar a internet lenta.
  • VPN WireGuard — quantos clientes estão conectados agora, do total ativo.
  • Portas liberadas — quantas liberações estão ativas e se os servidores estão respondendo.
  • Tráfego da internet — velocidade de download/upload do seu link ao longo do tempo (precisa da Interface WAN configurada).
  • Eventos recentes — últimos acontecimentos: alguém conectou, servidor caiu, porta expirou…

🔐 VPN WireGuard

Uma VPN cria um "túnel" seguro entre um dispositivo (celular, notebook) e sua rede. Com ela você acessa de qualquer lugar as coisas de casa/empresa — câmeras, NAS, servidores, impressoras — como se estivesse lá.

Configuração inicial (uma vez só)

  • Nome da interface / Porta UDP — pode deixar o padrão.
  • Faixa da VPN — os endereços que os clientes da VPN recebem. Precisa ser diferente da sua rede (ex.: sua rede é 192.168.88.x → use 10.10.0.x).
  • Endereço remoto — por onde os clientes te encontram na internet. Prefira o DDNS (….sn.mynetname.net), pois o IP pode mudar.
  • Endereço local — IP do MikroTik na sua rede, para usar a VPN de dentro de casa.

Clientes

Cada dispositivo deve ter seu próprio cliente (não compartilhe o mesmo QR entre aparelhos). Ao criar, escolha:

  • 🏠 Só rede local — acessa sua rede; a internet do aparelho continua normal. Recomendado na maioria dos casos.
  • 🌐 Toda a internet — toda a navegação passa pelo seu MikroTik. Útil em Wi-Fi público ou para "parecer" que está em casa.

Como instalar no dispositivo

  • Celular — app "WireGuard" (Play Store / App Store) → + → Escanear QR code → ativar.
  • Windows/Mac/Linux — instale em wireguard.com/install → "Importar túnel de arquivo" → selecione o .conf → Ativar.

🎮 Liberação de portas

Também chamado de port forward ou redirecionamento de porta. Permite que pessoas na internet acessem um serviço da sua rede — por exemplo, amigos entrando no seu servidor de Minecraft.

Antes de liberar

  • Fixe o IP do servidor: no Winbox, IP → DHCP Server → Leases → clique no servidor → Make Static. Se o IP mudar, a liberação para de funcionar.
  • Libere também o firewall do próprio servidor (ex.: Firewall do Windows).

Campos

  • Modelo pronto — preenche as portas certas de jogos e apps conhecidos.
  • Porta externa — a porta que as pessoas usam na internet. Aceita 25565, faixa 2456-2458 ou lista 80,443.
  • IP do servidor / Porta interna — para onde o tráfego vai. Porta interna em branco = mesma da externa.
  • Permitir apenas destes IPs — só esses endereços conseguem acessar. Ótimo para jogar só com amigos ou para RDP/SSH.
  • Fechar automaticamente — a porta fecha sozinha no horário escolhido (ex.: liberar só no fim de semana).
  • Monitorar se está no ar — o painel testa a porta do servidor e avisa se ele cair (apenas TCP).

📈 Monitoramento

  • Gráfico — escolha um cliente VPN ou uma porta liberada e o período (1 hora a 30 dias). Para VPN: Download = o que o dispositivo recebeu; Upload = o que enviou. "Online X% do tempo" mostra quanto ficou conectado. Para portas: tráfego que entrou e a disponibilidade do servidor.
  • Consumo por cliente — quanto cada dispositivo usou no período e quando foi visto por último.

O histórico é guardado pelo tempo definido em Configurações (padrão 30 dias).

🔔 Eventos

Linha do tempo automática do sistema: conexões e desconexões da VPN, servidores que caíram/voltaram, portas que expiraram e quedas do MikroTik. Tudo é registrado aqui, mesmo o que não gera alerta.

Cores: success algo bom · info informativo · warn atenção · error problema.

📣 Alertas admin

Envia os eventos para o seu celular via Discord e/ou Telegram.

  • Discord — no canal desejado: Editar canal → Integrações → Webhooks → Novo webhook → Copiar URL. Cole no painel e ative.
  • Telegram — crie um bot com o @BotFather (/newbot), mande uma mensagem para o bot e pegue o Chat ID em api.telegram.org/bot<TOKEN>/getUpdates.
  • Quando avisar — escolha quais eventos geram mensagem.
  • Use Salvar e enviar teste para confirmar que chegou.

👥 Usuários admin

  • Administrador — pode tudo: criar/remover clientes e portas, ver QR codes, mudar configurações.
  • Somente leitura — vê status, gráficos e eventos, mas não altera nada nem vê QR codes/chaves. Ideal para quem só precisa acompanhar.

Estes usuários são só do painel — não têm relação com os usuários do MikroTik.

💾 Backup admin

  • Baixar backup — arquivo com tudo do painel (clientes e chaves, portas, configurações, usuários). Guarde em local seguro: quem tiver o arquivo consegue entrar na sua VPN.
  • Restaurar — importa um backup (ex.: ao trocar de computador). Pode recriar no MikroTik o que estiver faltando.
  • Backup do MikroTik — salva a configuração inteira do roteador dentro dele (Winbox → Files). Faça antes de mudanças grandes.

⚙️ Configurações admin

  • Endereço remoto / local — usados nos QR codes e arquivos da VPN. Mudou o DDNS? Atualize aqui e gere os QR codes de novo.
  • Redes acessíveis — o que o modo "Só rede local" alcança.
  • DNS / Keepalive / MTU — avançado; os padrões funcionam na maioria dos casos.
  • Identificação do tráfego da internet (NAT) — mantenha "Lista de interfaces WAN" se o seu MikroTik usa a configuração padrão.
  • Interface WAN — a interface da internet (ex.: pppoe-out1) para o gráfico do Painel.
  • Considerar offline após — quanto tempo sem comunicação até um cliente aparecer como offline.

📜 Auditoria admin

Registro de quem fez o quê e quando: logins, clientes criados/removidos, portas abertas, QR codes visualizados, configurações alteradas.

📚 Glossário

WireGuard
Tecnologia de VPN moderna, rápida e segura, já embutida no MikroTik (RouterOS 7).
Peer / Cliente
Cada dispositivo autorizado a conectar na VPN.
Handshake
"Aperto de mão" periódico entre o dispositivo e o MikroTik. Se aconteceu há pouco, o cliente está conectado.
Endpoint
Endereço (IP ou DDNS + porta) onde o cliente encontra o MikroTik.
DDNS
Um nome fixo (ex.: xxxx.sn.mynetname.net) que sempre aponta para seu IP, mesmo que ele mude.
NAT / Port forward
Regra que encaminha quem chega da internet numa porta para um aparelho da sua rede.
TCP / UDP
Tipos de comunicação. Cada jogo/app usa um (ou ambos) — os modelos prontos já sabem qual.
WAN / LAN
WAN = lado da internet. LAN = sua rede interna.
CGNAT
Quando a operadora não te dá um IP público próprio. Impede liberar portas e receber VPN — peça IP público à operadora.
Split / Full tunnel
"Só rede local" / "Toda a internet" pela VPN.
Whitelist
Lista de IPs permitidos; todos os outros são bloqueados.

🛠️ Problemas comuns

MikroTik offlineConfira IP e senha no arquivo .env, se o serviço www-ssl está ativo (IP → Services) e se o computador do painel está na rede permitida. Após editar o .env, rode docker compose up -d.
VPN conecta mas não acessa nadaEm VPN → Reconfigurar, deixe marcado "Tratar a VPN como rede interna" e aplique de novo.
VPN funciona em casa, mas não foraUse o QR de Acesso remoto fora de casa. Verifique se o endereço remoto (DDNS) está certo em Configurações.
Cliente aparece Offline mas está conectadoNormal se ficar parado sem uso por alguns minutos com keepalive desligado. Com o padrão (25s) não acontece.
Porta liberada não funcionaIP do servidor mudou (faça o lease estático), firewall do servidor bloqueando, programa fechado ou teste feito de dentro da própria rede (teste pelo 4G).
"Fora do ar" no serviçoO painel não conseguiu conectar no servidor interno: ele está desligado, o programa não está rodando ou a porta interna está errada.
Esqueci a senha do painelOutro admin pode redefinir em Usuários. Sem nenhum admin: apague a pasta data/ (perde os dados do painel — faça backup antes) e reinicie.
